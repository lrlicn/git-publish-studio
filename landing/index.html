FEATURES

为你把关，也让你省心

把零散的命令行封装成清晰的四步流水线，并内置一套安全护栏。

只在本地运行

服务仅监听 127.0.0.1，不向局域网开放，仓库与记录都不离开你的电脑。

可视化四步流水线

准备 → 暂存 → 提交 → 同步，引导式完成每一次发布，无需记忆命令。

操作输出全可见

所有 Git 操作输出都展示在界面内，配合中文说明更容易理解每一步发生了什么。

敏感与超大文件提醒

暂存前自动识别疑似密钥、凭据与接近 100MB 的大文件，防止误提交。

冲突与变基引导

遇到合并冲突与变基中断时，提供可读的修复建议与继续操作，不再手足无措。

内置目录浏览器

选择任意盘符与文件夹，不限制工作目录，也无须额外的系统选择器组件。

WORKFLOW

一次发布，四步搞定

从打开项目到推送到远端，全程无需离开键盘，也无需打开终端。

  1. 01

    准备

    选择或克隆仓库，配置提交身份与远端地址。

  2. 02

    暂存

    浏览文件变更，确认风险项后一键暂存。

  3. 03

    提交

    填写规范提交说明，提交前可查看 Diff 校对。

  4. 04

    同步

    获取、拉取并变基、推送，安全地覆盖远程分支。

GET STARTED

快速开始

需要本机已安装 git 与 Node.js。三步即可运行这款本地工作台。

1

下载源码

从开源仓库获取或克隆本项目。

git clone https://github.com/lrlicn/git-publish-studio.git
cd git-publish-studio
2

安装依赖

仅需一个轻量依赖。

npm install
3

启动

打开终端提示的本机地址即可。

npm start

开始你的第一次图形化 Git 发布。
